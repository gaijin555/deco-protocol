# Как участвовать в DeCo

Спасибо, что хотите помочь. DeCo — общественное благо, и каждый вклад важен.

## 🧩 Что можно делать

- **Код**: смарт-контракты, ноды, API-шлюзы, интеграции с 1С
- **Документация**: архитектура, юридические разборы, гайды
- **Переводы**: манифест и docs на другие языки
- **Юридическая экспертиза**: анализ по юрисдикциям
- **Экономика**: модели паевого токена и ресурсного баланса
- **Пилоты**: запуск локальных ячеек в вашем регионе

## 🛠 Процесс

1. Форкните репозиторий.
2. Создайте ветку: `git checkout -b feature/your-feature`.
3. Внесите изменения.
4. Убедитесь, что код проходит линтеры и тесты.
5. Откройте Pull Request с описанием: что, зачем, как проверить.
6. Дождитесь ревью от мейнтейнеров или сообщества.

## 📐 Правила

- Один PR — одна задача.
- Коммиты на русском или английском, но единообразно в рамках PR.
- Не коммитьте секреты, ключи, персональные данные.
- Уважайте [Кодекс поведения](./CODE_OF_CONDUCT.md).
- Юридические утверждения в docs сопровождайте ссылками на источники.

## 🧪 Тесты

- Смарт-контракты: `npm run test:contracts`
- Ноды: `npm run test:nodes`
- Документация: проверка ссылок через `npm run lint:docs`

## 🌱 Первые задачи

Ищите метку `good first issue` — это задачи для новичков.

## 💬 Обсуждения

- Issues — баги и предложения
- Discussions — идеи, вопросы, юридические разборы

## 🚫 Чего мы не делаем

- Не принимаем код с закрытыми лицензиями.
- Не принимаем PR, которые вводят скрытые комиссии или админ-ключи
  без явного одобрения DAO.
- Не принимаем рекламу и спекулятивные схемы.

**Спасибо, что строите вместе с нами.**
