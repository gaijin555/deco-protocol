# DeCo — Decentralized Cooperative Infrastructure

**Открытый протокол автономного жизнеобеспечения сообществ.**

DeCo — некоммерческий, полностью открытый, децентрализованный протокол,
который соединяет блокчейн-криптографию (TON) и традицию потребительской
кооперации. У проекта нет владельцев, акций и скрытых комиссий.
Это общественное благо (Public Good), созданное людьми для людей.

> Мы — распределённая сеть доверия.
